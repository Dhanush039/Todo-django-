# Django Todo App

A simple **Todo List application** built using Django.
It allows users to create, view, edit, and delete tasks.

## Features

* Add new tasks
* View tasks
* Edit tasks
* Delete tasks

## Technologies Used

* Python
* Django
* HTML
* CSS
* SQLite
